WireShare: Software KVM Architecture

Seamlessly share your wired PC Keyboard & Mouse with your Android phone over Wi-Fi

Key Innovation 1 Hybrid Network Transport

Unlike standard remote desktop apps that force all traffic over TCP, WireShare separates high-frequency mouse motion onto stateless UDP datagrams (120Hz) while keeping critical keystrokes and authentication on reliable WebSockets.

Key Innovation 2 Rootless Accessibility Injection

By implementing a custom AccessibilityService, WireShare draws a floating mouse cursor on top of any app and injects single taps, long presses, multi-step drags, and natural inertia scrolling without needing root access or an ADB cable.

Windows PC Server (`pynput` Input Trapping)

How the PC server intercepts your keyboard and mouse without letting Windows execute the inputs:

Low-Level Win32 Hook Suppression

By instantiating pynput.keyboard.Listener(suppress=True) and pynput.mouse.Listener(suppress=True), the Windows hook callback returns non-zero when in PHONE_CONTROL mode.

This tells the Windows OS Explorer and active desktop apps to ignore the event, preventing your PC cursor from moving while you control your phone.

Safety Dead-Man Switch

What if your Wi-Fi drops while control is switched to your phone? WireShare has 3 hardware-level failsafes:

  • Pressing Escape 3 times rapidly immediately restores Windows input.
  • Pressing Ctrl + Alt + Delete breaks any user-mode Win32 hook automatically.
  • An automatic 30-second ping timeout releases the hook if the Android client stops responding.

Android Accessibility Service & Gesture Injection

How WireShare converts network coordinates into native Android touches:

PC Hardware Action Android Injection Mechanism Latency (ms)
Mouse Move (dx, dy) Updates FloatingCursorView X/Y overlay position via Choreographer VSYNC. ~1.0 ms
Left Click (Press/Release) Executes AccessibilityService.dispatchGesture() single tap (duration 30ms). ~2.0 ms
Left Click Drag Executes continuous stroke path from anchor point until KEY_UP received. ~3.0 ms
Right Click Triggers performGlobalAction(GLOBAL_ACTION_BACK). ~1.5 ms
Middle Click Triggers performGlobalAction(GLOBAL_ACTION_HOME) or Recents. ~1.5 ms
Keyboard Typing Injects text into focused node via ACTION_SET_TEXT or IME Bridge. ~2.0 ms
